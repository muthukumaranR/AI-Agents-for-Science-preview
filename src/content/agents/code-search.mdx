The Code Search Agent is a Tool-Integrated agent designed through the AKD-CARE process. It requires external tools, APIs, or data systems for execution along with rigorous prompt design and reasoning.

Given a task description and constraints, the Code Search Agent surfaces candidate repositories with rationale, helping scientists find relevant codebases without manual searching. The agent is designed to support the scientific community in discovering and reusing existing scientific code, reducing duplication of effort and accelerating research workflows.
