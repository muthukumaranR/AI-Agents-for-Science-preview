The Planetary Data Search Agent is a Tool-Integrated agent designed through the AKD-CARE process. It requires external tools and data system integrations for execution, along with rigorous prompt design and reasoning to support scientists searching NASA's Planetary Data System archives.

Given a target body, instrument, and time range, the PDS Agent searches NASA's Planetary Data System archives and returns matched products with supporting context. Scientists retain authority over dataset selection and scientific interpretation.
