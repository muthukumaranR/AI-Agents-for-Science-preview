The PDS Search Agent is an AKD agent for discovering datasets and products across NASA's Planetary Data System. It performs catalog-first routing through broad discovery with cross-node PDS tools, then narrows results via node-specific services when needed. The agent returns both PDS4 and PDS3 versions of the same data when available. Like the other AKD data discovery agents, it never downloads, endorses, or interprets results.

The agent uses PDS node websites and node-operated services across GEO, ATM, IMG, PPI, RMS, and SBN. It searches broadly first via the PDS catalog and PDS4 tools, checks for both PDS4 and PDS3 representations, and narrows results with node-specific tools (ODE/GEO for Mars, IMG for imaging, OPUS/RMS for ring-moon systems, SBN for small bodies) when needed.
