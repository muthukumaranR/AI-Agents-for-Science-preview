The Astro Data Search Agent is a Tool-Integrated agent designed through the AKD-CARE process for discovering astronomical datasets across NASA astrophysics archives. Accepts a science target, wavelength, and epoch and returns archive matches with supporting references from NASA astrophysics data systems.

The agent is part of the broader AKD agents collection, supporting the scientific community in navigating complex astrophysics data archives with structured, evidence-based search and transparent discovery.
