The Astro Search Agent is an AKD agent for discovering astronomical datasets across NASA's astrophysics archives. The agent understands object names and coordinates to route queries to the appropriate archives, and it supports a diverse range of search patterns, including those driven by literature, coordinates, archives, or specific events.

Tools and data sources for the agent include SIMBAD, NASA ADS, MAST, HEASARC, IRSA, NED, Gaia, VizieR, and Virtual Observatory services, all routed via the Astroquery MCP server. The agent identifies which of the four search patterns applies, asks focused clarifying questions, resolves object names via SIMBAD, and routes to the right archive (HEASARC for high-energy, MAST for UV/optical space, IRSA for infrared, NED for extragalactic, Gaia for astrometry, ADS for literature).
