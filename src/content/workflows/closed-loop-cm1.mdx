The Climate Modeling Workflow is a multi-agent closed-loop workflow that chains specialized AKD agents across the scientific research lifecycle for climate model research. The workflow orchestrates gap analysis, Earth science data search, and code discovery into a unified pipeline, enabling researchers to move from identifying knowledge gaps to locating relevant datasets and reusable code — with human approval between each stage.

The workflow is implemented as a Closed-Loop Workflow (CLW) in AKD Flow, where agents are connected into a graph and executed with streaming updates and guardrail badges at each node.
