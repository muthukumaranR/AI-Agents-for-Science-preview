Why this matters

From utility tool to cognitive partner for scientific work.

AKD reframes AI in science: not as a one-shot assistant that answers a question, but as a disciplined collaborator embedded inside the scientific method. Agents help scientists frame problems, gather and reconcile data, propose analyses, and surface evidence — while every consequential step remains under expert review.

The ecosystem is built around closed-loop workflows, reproducibility, transparency of reasoning, and open release. We treat scientific accountability as a first-class engineering requirement — not a checkbox at the end.

Strategic objectives

Four commitments that shape every agent we ship.

OBJ · 01

Reclaim Scientist Time

Automate the toil — discovery, retrieval, reformatting, boilerplate analysis — so researchers spend their attention on hypothesis, interpretation, and judgment.

OBJ · 02

Cross-Disciplinary Orchestration

Compose agents across Earth, planetary, astrophysical, and climate domains so that workflows can span boundaries that traditional tooling has kept rigid and siloed.

OBJ · 03

Uniform Infrastructure Integration

One foundation — common interfaces for tools, models, guardrails, MCP servers, and workflow streams — so new agents inherit the platform instead of rebuilding it.

OBJ · 04

Scientific Integrity & Guardrails

Every agent ships with explicit guardrails: provenance, attribution, risk taxonomies, output checks, and review gates that protect the integrity of NASA science.

Design with CARE

Collaborative Agent Reasoning Engineering.

CARE is a disciplined, stage-gated methodology for engineering scientific AI agents together with subject-matter experts, developers, and helper LLM agents. Each phase produces an explicit artifact that the next phase can review, challenge, and extend.

SD

Scope & Decompose

Frame the scientific task, identify boundaries, and break the problem into reasoning steps that map cleanly to tools, data, and review points.

KE

Key Information Elicitation

Work with SMEs to surface the specialized knowledge, datasets, vocabulary, and edge cases an agent must understand to produce credible outputs.

RP

Reasoning Policy & Guardrails

Encode how the agent is allowed to reason: tool-use policies, escalation rules, refusal cases, and output checks tied to a domain risk taxonomy.

IM

Implementation

Build the agent on top of akd-core and akd-ext with shared tooling, streaming, and human-in-the-loop hooks.

BV

Benchmarking & Verification

Evaluate against curated tasks in AKD Labs, capture failure modes, and only promote agents that pass the SME review gate before publication.

AKD software ecosystem

A shared foundation for every scientific agent we build.

akd-core and akd-ext form the base layer for domain agents, tools, guardrails, streaming workflows, MCP integration, and human-in-the-loop review. Higher layers handle benchmarking, deployment, and discovery.

FOUNDATIONcore

akd-core

The base library: agent abstractions, tool interfaces, reasoning loops, streaming primitives, MCP adapters, and human-in-the-loop hooks shared by every agent in the ecosystem.

EXTENSIONSext

akd-ext

Domain extensions and shared utilities — connectors, retrieval helpers, evaluators, and reusable building blocks that complement akd-core for real scientific tasks.

RUNTIMEflow

AKD Flow

Workflow runtime for chaining published agents into multi-step, human-reviewed pipelines — with explicit approval gates, traceable state, and reproducible runs.

WORKBENCHlabs

AKD Labs

The build-and-benchmark workbench where new agents are prototyped, evaluated against curated science tasks, and stress-tested before they reach the SME review gate.

SAFETYguard

Science Guardrails

Output-level safety: a NASA science risk taxonomy plus integrated checks like Granite Guardian, FactReasoner, and a Risk Agent that gate what an agent is allowed to publish.

DISCOVERYhub

Agent Hub & Documentation

The catalog and docs surface for published agents: usage, scope, inputs, outputs, evaluation notes, and how to compose them into community workflows.

Science guardrails

Trustworthy by construction — not as a postscript.

Guardrails in AKD work as output checks, not just input filters. Before an agent's response is allowed to flow downstream, it is evaluated against a NASA science-specific risk taxonomy and a stack of guardrail components designed for scientific reliability.

Layer 01

Granite Guardian

Foundation-model-level safety checks integrated into the AKD pipeline to flag policy-violating or unsafe content before it reaches the user.

Layer 02

Risk Agent

An agent that evaluates outputs against the NASA science-specific risk taxonomy — surfacing the categories of risk a given response might trigger.

Layer 03

FactReasoner

Verifies factual and citation grounding so generated content stays anchored to identifiable sources and traceable reasoning.

Layer 04

NASA Science Risk Taxonomy

A purpose-built taxonomy that defines what "going wrong" looks like in scientific outputs — and turns that into checks the system can actually run.

Risk taxonomy · what we mitigate

Failure modes the guardrails are tuned for.

R · 01
Hallucination
Plausible-sounding but unsupported scientific claims, datasets, or references.
R · 02
Attribution gaps
Claims presented without traceable sources, citations, or provenance metadata.
R · 03
Outdated confidence
Confidently presenting information that has since been superseded or revised.
R · 04
Overgeneralization
Extending narrow findings beyond the conditions, regions, or scales they were established under.
R · 05
Unsupported claims
Conclusions that exceed what the cited evidence and reasoning chain actually establish.
